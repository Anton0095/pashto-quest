# Pashto Quest — one-page language reviewer handout

**Thank you for helping assess the language in a Pashto-learning game.** The game is set in a fictional village in Laghman. We want Pashto that is understandable, grammatically accurate and natural for the intended speaker and listener. You are **not** being asked to review software code.

### What we need from you

For each word, word form, dialogue line or example sentence, please tell us:

1. **Correct?** Is the Pashto spelling and meaning correct for the exact English translation shown?
2. **Natural?** Would someone in Laghman say it this way in that situation? If you would say something else, write it.
3. **Grammar?** Does it use the right verb form, singular/plural, gender, formality or case?
4. **Pronunciation?** Is the printed Latin-letter pronunciation useful and, if audio plays, is the spoken Pashto correct?
5. **Alternatives?** Are there other acceptable ways to say the same thing? Please distinguish common spoken variants from the formal written form.

Please preserve the original Pashto and English columns. Write corrections in the **corrected** columns. Use `ACCEPT`, `REVISE`, `REJECT` or `UNCERTAIN` in `review_decision`. If you are unsure about a regional form, writing `UNCERTAIN` is helpful—there is no need to guess.

### Which files should I open?

- Start with [Day-by-day checklist](WEEK1_DAILY_CHECKLIST.md), then use the matching daily rows in [words](WEEK1_LEXEME_REVIEW.csv) and [forms](WEEK1_FORM_REVIEW.csv).
- For nouns and plurals from Day 5, use the [noun morphology list](WEEK1_NOUN_MORPHOLOGY_REVIEW.csv).
- For greetings, onboarding and Bilal's speech, use [dialogue and fixed-language review](WEEK1_FIXED_LANGUAGE_REVIEW.csv).
- The [grammar list](WEEK1_GRAMMAR_REVIEW.csv) contains the English explanations the game uses. Please assess whether these rules and examples describe Pashto correctly.

Every row has an ID so we can find the exact item again. **You do not need to understand those IDs.** Do not change or remove them.

### First review session

Begin with **Day 1 and Day 2** before attempting hundreds of forms. Check the actual Day 1 greetings and teaching examples, then compare the Day 2 “he/she” verb sentences with their English meanings. Mark every correction or uncertain phrase. The project will then correct those issues and request a short follow-up review of the changed material.

A later session will examine Day 5 plurals and the more complex pronouns, verbs and sentences of Days 3–7.

### Useful review comments

Good comments are specific, for example:

- “This word means X rather than Y in this context.”
- “This pronunciation suggests the wrong vowel.”
- “This verb form addresses one friend, but this character is addressing an elder.”
- “The written form is acceptable, but in Laghman I would normally say …”
- “These are both correct, but only in the following situations …”
- “The noun is not normally counted this way.”

If possible, attach a brief spoken explanation or example recording **only with permission to store/use that recording**. A private discussion can be documented by a reviewer code and evidence note without publishing anyone's name.

### Important boundaries

The current worksheets contain the game team's **existing, unverified** Pashto. They are not reference translations supplied by an independent Pashto expert. Some entries were approved previously by the project owner for their base spelling/meaning only; many inflections and sentences have not been independently approved. Your judgement is therefore valuable even when a status column already says `user_approved`.

Your worksheet responses are review **recommendations**. A developer will apply the corrections in the game and send back the changed version for confirmation. Please do not mark all items approved merely because the game displays them or because the same word appears more than once.

See the [full reviewer protocol](REVIEWER_PROTOCOL.md) if you need the grading and evidence rules.

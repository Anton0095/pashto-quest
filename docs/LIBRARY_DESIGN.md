# Current Library contract

The Library is an always-open reference overlay, not a daily teaching visit. It preserves the active lesson/challenge, keyboard focus and saved attempt. Home/Lake/Market/School remain the four quota buckets. Hills is a Nature narrative scene.

An acquired word is a stable dictionary lemma, not a token, English gloss or hypothetical stem. Explicit form IDs capture conjugation, number and agreement without adding quota. Contextual card IDs reference those forms; they do not own parallel lexical counters. Grammar and greeting expressions do not consume content-lemma quota.

Paces 4/8/12/16/20/24 allocate 1–6 new distinct content lemmas per district; optional zero permits review. Default is 20. Onboarding does not freeze Day 1 prematurely. A started plan cannot reroll or change after settings changes. Day 14 always assigns zero compulsory new words.

Scheduled, actually encountered scheduled, incidental story, reviewed existing and mastered lemma totals are distinct. Actual study/question exposure introduces forms; submitted answers practise them. Viewing Library, selecting a plan, skipping a visit or passing a day does not grant unseen vocabulary/mastery. Missing pool capacity is displayed without invented Pashto or repeat-as-new credit.

The Vocabulary Bank searches/filters only acquired entries and shows encountered forms, pronunciation support, context, status and due revision. The Grammar Journal unlocks from actual exposure or correctly demonstrated grammar. Greetings remain separate. Library practice changes SRS but grants no XP.

One scheduler updates forms and nonlexical sentence/expression skills. The acquired bank owns lexical form state; sentence/expression units represent distinct recall tasks using the same scheduling algorithm. A newly encountered form removes any premature family-wide mastery label. Incorrect answers reset the affected skill's stage/due date. Correct spaced attempts advance it; repeat submission of one event is idempotent.

Questions retain fixed authored grammar/narrative contexts. Lexical selection prioritises genuine acquired/due entries and identifies scheduled unfamiliar scaffolds. Selected questions and live attempts are saved, including tile indices, index, submitted answer, first-answer lock, score and earned XP. Restore reconstructs feedback without regrading. Permanent reward keys block immediate replay farming; first-pass milestones remain once-only.

Unstudied challenge words use Pashto-to-English recognition with transliteration, the neutral “Not previously studied” warning and pronunciation. Their English solution appears only as an ordinary answer option until submission locks the answer, then in feedback. Presentation is frozen in the attempt before exposure so an unanswered reload cannot turn recognition into an English prompt; existing question-only exposure with no attempts is also handled for current-schema saves. Previously studied words keep their normal direction and presentation. Skipping does not reduce the score automatically.

The current release supports save schema 4 only. Incompatible/corrupt stored data remains unchanged until explicit reset. There are no old-format imports, previous-place adapters or historical-clear backfills.

The single offline release bundles all text/data. Native Laghman review, verified pronunciation and additional translated vocabulary remain editorial prerequisites. Untranslated candidate records are not part of the playable lexicon. The activation/build gates require complete metadata and documented review for promotion.

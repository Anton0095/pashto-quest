# Experience and milestone contract

XP is cumulative and nonnegative. Nominal levels use 200 XP steps, capped by contiguous daily clears:

| First clear | Minimum XP | Level cap |
|---|---:|---:|
| None | 0 | 1 |
| Day 1 | 200 | 2 |
| Day 2 | 400 | 3 |
| Day 3 | 600 | 4 |
| Day 4 | 800 | 5 |
| Day 5 | 1200 | 7 |
| Day 6 | 1600 | 9 |
| Actual Day 7 exam | 1800 | 10 |

Only passing the actual 25-question Day 7 examination unlocks New Resident. A player making zero optional visits and passing each assessment at the exact threshold reaches that milestone. XP above a progress gate remains banked and is displayed honestly.

Daily pass thresholds are 12/15, except Days 7 and 14 at 20/25. A first Week 1 pass can retain its 75-XP bonus and receives any necessary floor top-up atomically with its clearance and milestone record. Failures and repeat clears do not repeat those awards. Day 1 first pass grants the home once. Week 2 has no additional approved level schedule and retains Level 10/New Resident.

Answer XP uses permanent reward identities. Initial correct practice is rewarded once per canonical skill identity; due review can receive at most one review reward per skill/calendar day. Immediate not-due repeats pay nothing. Challenge question rewards and lesson completion/milestone bonuses are once-only. Library voluntary practice grants no XP. Reconstructing saved feedback never grades or rewards again.

Save schema 4 is the only supported format. There is no milestone reconciliation from old saves; an incompatible save requires explicit reset. The archived historical algorithm can be found in Git history, not in the current runtime.
